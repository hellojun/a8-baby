# a8.baby

个人主页（单页静态站）。内容整理自 GitHub 上的个人与组织仓库。

- 文件：`index.html`，直接用浏览器打开即可预览，无构建步骤。
- 视觉：深色「账本」风，呼应 LLMChain 的「收据即结算」。一个暗底、一个暖纸色收据、一个琥珀强调色；IBM Plex Mono 做编号与标签，Space Grotesk 做拉丁项目名，Noto Sans SC 做中文。
- 交互：首屏收据可「再开一张」（PENDING → SETTLED）、公开仓库按语言筛选、复制 Telegram、移动端汉堡菜单；尊重 `prefers-reduced-motion`。
- 部署：GitHub Pages（main 分支根目录），自定义域名 a8.baby（见 `CNAME`）。
- 联系方式：Telegram @Jun0bj
