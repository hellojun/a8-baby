LLMChain：给 Agent 经济开发票的链

人类交易靠发票，Agent 交易靠什么？一天成千上万次推理调用，没有任何凭证能证明它真的发生过、用的是声明的模型、价格是约定的价格。LLMChain 是一条把每次推理调用变成可验证收据（VSR）并原生结算的独立公链。

  • 收据即结算每一次完成的推理调用生成一张 VSR 收据，收据是唯一上链的对象。
  • 毫秒级调用选服务商、付款、执行都在链下，只有结算上链，不等区块确认。
  • 造假不划算隐蔽挑战、分级保真证明、质押罚没，以次充好在经济上亏本。
  • 补上缺的半段x402 解决怎么付钱，ERC-8004 解决 Agent 是谁，LLMChain 解决调用是否真实、多方如何结清。

基金会做链，社区做生态。白皮书 v1.1 刚放出来，还有不少【待定】。如果你对可验证推理、支付通道、TEE 或 zkML 有想法，欢迎来提 issue、挑毛病、一起把它做出来。

    Agent × 链

    PolySport、Bout 协议、KPAX Ball、OXN 机密 EVM 测试网、园区存证 BaaS，以及做市与多因子量化系统。还写了一个把 Lark 告警交给本地 Codex 结合 SSH 日志做分析的小服务。
