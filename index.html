LLMChain：把闲散的大模型聚到链上，给 Agent 用

世界上有大量闲着的 GPU 和自己托管的开源模型，也有越来越多的 Agent 一天要发起成千上万次推理调用。LLMChain 是一条独立公链，把这两头接起来：谁有模型谁就能上链挂单，Agent 按模型、价格、证明等级直接挑选并付款，每一次调用都生成一张可验证的收据（VSR），收据即结算。人类交易靠发票，Agent 交易靠 VSR。

  • 供给：闲散模型上链普通 GPU 自托管开源权重即可挂单，无需许可；链上挂单簿持久有效，写明模型、单价、容量和证明等级。
  • 需求：Agent 直连，毫秒级Agent 查挂单簿选服务商，用 x402 开支付通道，链下当场接单执行，不等区块确认，只有结算上链。
  • 凭证：收据即结算每一次完成的推理调用生成一张 VSR 收据，它是唯一上链的对象，资金按收据结算，没有平台托管。
  • 信任：造假不划算隐蔽挑战、分级保真证明、质押罚没，让挂旗舰模型却偷换小模型这种事在经济上亏本。

基金会只做足够薄的验证与结算底座，分账、路由这些生态逻辑交给社区在合约层演进。白皮书 v1.1 刚放出来，还有不少【待定】。如果你手里有闲着的 GPU，或者对可验证推理、支付通道、TEE、zkML 有想法，欢迎来提 issue、挑毛病、一起把它做出来。

  2. 2020

    做了一阵传统业务

    给一家摄影品牌做微信 Native 支付和智能影棚系统。

  3. 2021–2022

    NFT 与游戏

    参与 1Box NFT 平台、Xoasis NFT 市场（含给 Unreal Engine 用的以太坊钱包 SDK）和 gamelink 链游项目。

  4. 2022–2023

    交易所级钱包系统

    发起 ex-wallet：Go 写的完整钱包后端，含充提、签名服务、风控服务、MPC 与 KMS、BTC/ETH/BSC/TRON/XRP 节点接入、运营后台。官网和部分后台 API 是我自己写的。

  5. 2023

    应用链与 DeFi

    用 Cosmos SDK 做了游戏应用链 gchain，拿到 Cosmos 香港加速器中文开发培训第 2 期黑客松第一名。同期发起 GreatGainGo，做预言机合约与节点。

    铭文那一波

    写了 Celestia、IoTeX、Cosmos 的铭文工具，发起 CelestLoan 和铭文市场项目。还写了个每秒盯币安上币公告、自动在 OKX 开多的小工具，意外成了我星星最多的仓库。

  7. 2024 末–2025

    Meme 交易与 AI 入门

    发起 memes-ai：微服务架构的多链 Meme 币交易平台（ETH/BSC/Base/Solana/Tron，带 MEV 保护）。同时写 Solana 节点服务、交易助手 TradeGPT，以及两个德州扑克 AI（一个用 LangChain，一个用 Claude API）。

  8. 2026

    Agent × 链

    PolySport、Bout 协议、KPAX Ball，以及做市与多因子量化系统。10 月发布 LLMChain 白皮书：聚合闲置的大模型算力上链供 Agent 调用。
